# 아마존 워터파크 준비물 체크리스트

두 가족(은영네 · 현주네) 워터파크 나들이 준비물을 나눠 챙기기 위한 한 장짜리 웹 체크리스트입니다.

- 어른 4 · 초등 3 · 중학생 1 / 13:00–22:00 / 카바나 + 취사(버너·불판 대여)
- 항목별 **완료 체크**, **담당 집 지정**, **메모** 지원
- 항목 추가 · 삭제, 담당별 필터, 진행률 표시

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체. 별도 빌드나 의존성 없음 |

## GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다 (예: `waterpark-checklist`, Public)
2. 저장소 화면에서 **Add file → Upload files**를 누르고 `index.html`과 `README.md`를 끌어다 놓습니다
3. 아래 **Commit changes** 버튼을 누르면 업로드 완료

## GitHub Pages로 링크 만들기

1. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. Source를 **Deploy from a branch**, 브랜치는 `main` / 폴더는 `/ (root)`로 지정하고 저장
3. 1~2분 뒤 `https://<아이디>.github.io/waterpark-checklist/` 주소가 생성됩니다

## 저장 방식에 대해

체크와 메모는 **접속한 브라우저에만 저장됩니다.** 기기 간 동기화는 없기 때문에, 두 집이 실시간으로 같은 목록을 보려면 GitHub Pages 대신 Claude 아티팩트 게시 링크를 쓰는 편이 낫습니다. (같은 파일을 Claude 아티팩트로 열면 자동으로 공유 저장소를 사용합니다.)

브라우저 저장 특성상 시크릿 모드에서는 새로고침 시 초기화되고, 브라우저 데이터를 지우면 체크 내역도 함께 사라집니다.
